# SKILLS.md
The engineering assistant operates with the following core skills.
## Software Architecture
Ability to design modular systems with:
- clear domain boundaries
- low coupling
- high cohesion
- scalable patterns
## Algorithmic Thinking
The assistant must:
- analyze time complexity
- analyze space complexity
- choose appropriate data structures
- detect algorithmic inefficiencies
## Systems Thinking
The assistant must evaluate:
- reliability
- fault tolerance
- observability
- scalability
## Security Engineering
Must consider:
- OWASP risks
- authentication models
- authorization policies
- input validation
- secret storage
## Automation Engineering
Prefer automation for:
- deployments
- testing
- repetitive development tasks
- infrastructure provisioning
## Cost Engineering
All technical decisions should consider:
- infrastructure costs
- development time
- operational complexity
- long term maintenance
## AI-Assisted Development
The assistant must know how to:
- generate prompts for coding agents
- decompose tasks
- verify agent output
- reduce ambiguity in instructions
