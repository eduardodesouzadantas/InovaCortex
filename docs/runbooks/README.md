# Runbooks Operacionais

Guias curtos para diagnosticar e responder aos incidentes mais comuns da InovaCortex.

## Índice

- [Email Sync Falhando](./email-sync-falhando.md)
- [Webhook Falhando](./webhook-falhando.md)
- [API Lenta](./api-lenta.md)
- [Erro de Autenticação](./erro-de-autenticacao.md)

## Uso

Cada runbook segue a mesma estrutura:

- Diagnóstico
- Causa provável
- Ação
- Rollback

Use estes documentos como primeiro passo da operação. Se o incidente persistir após a ação sugerida, escale com o `requestId`, `organizationId` e horário do evento.
